## 🎓 Key Concepts

### Model Formats
1. **H5 (Keras)** - Original training format
   - Pro: Easy to modify and retrain
   - Con: Slower inference, larger size
   
2. **ONNX** - Intermediate portable format
   - Pro: Platform independent, widely supported
   - Con: Not optimized for specific hardware
   
3. **TensorRT** - Optimized for NVIDIA hardware
   - Pro: Fastest inference, optimized for Jetson
   - Con: Hardware specific, needs conversion

### Precision Modes
- **FP32** - Full 32-bit precision (default)
  - Higher accuracy, slower
  
- **FP16** - Half precision (recommended for Jetson)
  - 2x faster, minimal accuracy loss
  - Best balance for Jetson Xavier NX
  
- **INT8** - 8-bit integer (requires calibration)
  - 4x faster, requires calibration data
  - Advanced users only

| Platform | Model Type | Time |
|----------|-----------|------|
| Jetson Xavier NX | TensorRT FP16 | 1-5 ms |
| Jetson Xavier NX | TensorRT FP32 | 2-8 ms |
| Jetson Xavier NX | ONNX Runtime | 5-15 ms |
| Jetson Xavier NX | Keras/TF | 10-30 ms |
| Desktop GPU (RTX 3080) | TensorRT FP16 | 0.5-2 ms |
| Desktop CPU (i7) | ONNX Runtime | 20-50 ms |

### Throughput (samples/second)
- TensorRT FP16: 200-1000 samples/sec
- TensorRT FP32: 125-500 samples/sec
- ONNX Runtime: 60-200 samples/sec

**For Real-time BCI:**
- Target: < 10 ms per classification
- Jetson Xavier NX with TensorRT FP16 easily achieves this ✅
