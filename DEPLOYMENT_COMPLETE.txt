Project: EEGNet-based Motor-Imagery Brain-Computer Interface
Source: ETH Zurich (2020)
Purpose: Real-time classification of motor imagery tasks from 64-channel EEG
Target: NVIDIA Jetson Xavier NX for edge deployment

Architecture:
  - Model: EEGNet (compact CNN for EEG signals)
  - Input: 64 channels × 480 samples (3 seconds @ 160 Hz)
  - Output: 4 classes (Left Hand, Right Hand, Both Feet, Rest)
  - Format: ONNX (16 KB)

🚀 QUICK START - 3 STEPS TO DEPLOY
════════════════════════════════════════════════════════════════════════════════

STEP 1: Transfer to Jetson
───────────────────────────
Option A - SCP:
  $ scp eegnet_jetson_deployment_*.tar.gz jetson@<jetson-ip>:~/
  $ ssh jetson@<jetson-ip>
  $ tar -xzf eegnet_jetson_deployment_*.tar.gz
  $ cd eegnet_jetson_deployment_*/

Option B - USB Drive:
  - Copy the .tar.gz file to USB drive
  - On Jetson: mount USB, copy file, extract

STEP 2: Run Setup (30-60 minutes)
──────────────────────────────────
  $ chmod +x jetson_setup.sh
  $ ./jetson_setup.sh

  This installs:
  • TensorFlow 2.7.0+nv22.1
  • Keras 2.6.0
  • ONNX Runtime 1.12.1
  • All dependencies

STEP 3: Run Inference
─────────────────────
  # Demo with synthetic data
  $ python3 jetson_inference.py --model models/output.onnx --mode demo

  # Benchmark performance
  $ python3 jetson_inference.py --model models/output.onnx --mode benchmark

🛠️ OPTIMIZATION OPTIONS
════════════════════════════════════════════════════════════════════════════════

1. Enable Maximum Performance:
   $ sudo nvpmodel -m 0        # Set to 20W MAXN mode
   $ sudo jetson_clocks        # Lock clocks to maximum

2. Monitor Performance:
   $ tegrastats                # Real-time GPU/CPU/memory stats
   $ jtop                      # Interactive monitoring (requires jetson-stats)

3. Convert to TensorRT (Advanced):
   For 2-3x speedup, convert ONNX to TensorRT:
   $ /usr/src/tensorrt/bin/trtexec --onnx=output.onnx --saveEngine=output.trt --fp16

🚨 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════════════════

Common Issues:

1. Out of Memory
   → Reduce batch size
   → Close unnecessary applications
   → Add swap space

2. TensorFlow Import Error
   → pip3 install --extra-index-url https://developer.download.nvidia.com/compute/redist/jp/v46 tensorflow==2.7.0+nv22.1

3. CUDA Not Available
   → Check: python3 -c "import tensorflow as tf; print(tf.config.list_physical_devices('GPU'))"
   → Verify: tegrastats | grep GR3D

4. Slow Inference (>10ms)
   → Enable max performance: sudo nvpmodel -m 0 && sudo jetson_clocks
   → Check thermal throttling: tegrastats | grep temp
   → Add cooling if overheating
